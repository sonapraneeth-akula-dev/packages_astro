`@sonapraneeth/notes-core` is the sibling of the blog engine: same route
injection, same MDX pipeline, same theme system — but built around a sidebar, a
folder tree and long-form handbooks instead of a dated feed. This post indexes
every feature, with screenshots from both demo sites.

<Callout type="tip">
  The flat-handbook screenshots come from `demo/notes`; the notebooks-mode ones
  from `demo/notebooks`. Regenerate them with `node
  scripts/capture-screenshots.ts notes` and `… notebooks`.
</Callout>

## The two entry points

```ts title="astro.config.ts"
import { defineDocsAstroConfig } from '@sonapraneeth/notes-core/astro';
import { docsConfig } from './notes.config';

export default defineDocsAstroConfig({
  port: 4310,
  docsConfig,
  contentDir: './content',
});
```

```ts title="notes.config.ts"
import { defineDocsConfig } from '@sonapraneeth/notes-core/config';

export const docsConfig = defineDocsConfig({
  brand: 'Notebooks',
  title: 'Notebooks — Demo',
  subject: 'Notebooks',
  notebooks: true,
  search: true,
});
```

### `defineDocsConfig` options

| Option | Type | Default | What it does |
| --- | --- | --- | --- |
| `brand` | `string` | `Grihasetu` | Short brand in the header |
| `title` | `string` | — | Full site name in `<title>` and metadata |
| `description` | `string` | — | Tagline / default meta description |
| `author` | `string` | — | Author shown in the footer and on notebook cards |
| `subject` | `string` | `Documentation` | Subject shown on the landing page |
| `timeZone` / `timeZoneLabel` | `string` | `Asia/Kolkata` / `IST` | Timestamp rendering |
| `editUrlBase` | `string` | — | Base URL for "Edit this page"; the doc id is appended |
| `search` | `boolean` | `true` | Build the Pagefind search page and index |
| `notebooks` | `boolean` | `false` | Treat each top-level folder as a self-contained notebook |
| `theme` | `ThemeConfig` | `{}` | Palette, font combo, radius, script fonts |
| `pwa` | `PwaConfig` | off | Manifest + service worker; disabled unless `pwa.enabled` |
| `captionAlign` | `CaptionAlignConfig` | `{ default: 'center' }` | Figure and numbered-block caption alignment |
| `printSectionNumbers` | `boolean` | `true` | Auto-number headings inside the notebook print view |
| `nav` / `socials` | arrays | home/categories/tags/search, GitHub | Header links and footer socials |

`defineDocsAstroConfig` takes the same shape as the blog factory: `port`,
`site`, `docsConfig`, `contentDir`, `components`, `integrations`,
`themeSwitcher` — plus an optional curated `sidebar`.

## Injected routes

| Pattern | Page |
| --- | --- |
| `/` | Landing page, or the notebook hub in notebooks mode |
| `/[...slug]` | A single note |
| `/categories`, `/categories/[category]` | Site-wide category index and pages |
| `/tags`, `/tags/[tag]` | Site-wide tag index and pages |
| `/[notebook]/categories`, `/[notebook]/categories/[category]` | Notebook-scoped categories (notebooks mode) |
| `/[notebook]/tags`, `/[notebook]/tags/[tag]` | Notebook-scoped tags (notebooks mode) |
| `/print/[notebook]` | Whole-notebook print view (notebooks mode) |
| `/search` | Pagefind search (only when `search: true`) |
| `/404` | Not-found page |

`index.mdx` files become group landing pages, and frontmatter tunes the result.

### Sidebar frontmatter

```yaml
sidebar:
  label: Configuration   # override the sidebar text
  order: 2               # sort within the folder (default: Infinity)
  hidden: false          # keep routable, drop from the sidebar
  badge: New             # small badge beside the entry
```

### Curated `sidebar.json`

Pass a `sidebar` to the Astro config to replace the generated tree entirely.
Four item shapes are supported:

<Steps>

1. `{ "doc": "getting-started/installation" }` — link a note by id, with an optional `label` and `badge`.
2. `{ "link": "https://…", "label": "Spec" }` — an external link.
3. `{ "group": "Guides", "items": [ … ] }` — a collapsible group.
4. `{ "divider": true }` — a visual separator.

</Steps>

<Callout type="caution">
  A curated sidebar takes over completely, so `notebooks` mode is ignored when
  one is supplied.
</Callout>

## Notebooks mode

Set `notebooks: true` and every top-level content folder becomes a
self-contained handbook: its own scoped sidebar, landing page, prev/next chain
and taxonomy routes. One site, several independent books.

## The print view

`/print/[notebook]` stitches an entire notebook into one document with page
breaks between chapters, then opens the print dialog — so "Save as PDF"
produces the whole handbook.

<DocImage
  id="fig-notebooks-print"
  src={notebooksPrint}
  alt="The print view for the C++ notebook, showing the cover block followed by the first chapter"
  caption="The print view at /print/cpp. Set `printInNotebook: false` on any screen-only page to exclude it."
/>

`printSectionNumbers` (site config, default `true`) numbers `##`/`###`/`####`
headings within each chapter. Turn it off for notebooks whose headings already
carry their own numbering.

## Note frontmatter

Validated by `docFrontmatterSchema` in `src/schema.ts`.

| Field | Type | Required | What it does |
| --- | --- | --- | --- |
| `title` | `string` | ✓ | Page title and default sidebar label |
| `description` | `string` | | Summary for metadata and hub cards |
| `author` | `string` | | Shown on the notebook hub card |
| `group` | `string` | | On a notebook's `index.mdx`: clusters notebooks on the hub |
| `slug` | `string` | | Custom route, overriding the file path |
| `sidebar` | `object` | | `label`, `order`, `hidden`, `badge` |
| `part` / `chapter` | `string` | | Feed the numbering system (e.g. `II`, `3`) |
| `category` | `string` | | Routable at `/categories/[category]` |
| `tags` | `string[]` | | Routable at `/tags/[tag]` |
| `keywords` | `string[]` | | Search-only aliases |
| `draft` | `boolean` | | Hide from the sidebar and listings |
| `publishedDate` / `lastUpdated` | `date` | | Dates shown in the page header |
| `cover` | `string` | | Emoji or glyph for the header or hub card |
| `coverImage` | `image` | | Local cover image, optimized by Astro |
| `card` | `'standard' \| 'book'` | | Hub card style |
| `tableOfContents` | `boolean` | | Show or hide the right-hand TOC (default `true`) |
| `printInNotebook` | `boolean` | | Include in the print view (default `true`) |
| `math` | `boolean` | | Reserved opt-in flag for LaTeX |
| `captionAlign` | `object` | | Per-page caption alignment override |

## Helpers a site can import

From `@sonapraneeth/notes-core`:

- **Routing and sidebar** — `buildDocRoutes`, `buildSidebar`, `flattenSidebar`, `buildHomeData`, `getNotebooks`, `groupNotebooks`, `notebookSegment`, `normalizePath`, `entrySlug`, `entryParam`, `entryLabel`, `isRootIndex`, `editUrl`.
- **Taxonomy** — `getLiveDocs`, `getCategories`, `getTags`, `docsInCategory`, `docsWithTag`.
- **Formatting** — `slugify`, `humanize`, `readingTime`, `truncateWords`, `coverInitials`, `coverHue`, `formatDateTime`.

The exported types (`SidebarNode`, `SidebarGroup`, `SidebarLeaf`, `DocLink`,
`Breadcrumb`, `Notebook`, `NotebookGroup`, `DocRoute`, `HomeData`) let a site
build custom pages on top of the same tree the engine uses.

## Shared with blog-core

Both engines are assembled from the same parts, so everything below behaves
identically on a notes site: Expressive Code, the Satteri MDX pipeline with
KaTeX and Mermaid, build-time numbering with `<Ref>` cross-links, the sitemap,
self-hosted theme fonts, the opt-in PWA, and the full MDX component map.
